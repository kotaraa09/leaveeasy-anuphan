# 🔧 LeaveEasy — ระบบขอลาออนไลน์

## 🌐 เปิดเว็บที่ใช้งานได้จริง

### 👉 https://leaveeasy-anuphan.web.app

ที่อยู่สำรองซึ่งชี้ไปที่เดียวกัน: <https://leaveeasy-anuphan.firebaseapp.com>

> เว็บนี้ต่อกับฐานข้อมูลจริงบน Firebase — ต้องสมัครสมาชิกและเข้าสู่ระบบก่อนจึงจะยื่นใบลาได้
> บัญชีที่สมัครเองจะได้บทบาท **ผู้ขอลา** เสมอ · เปลี่ยนเป็น `manager` / `hr` ต้องแก้ใน Firebase Console

---

**ADT-RAISE Non-Degree Batch 2 · Module 2: MVP-Ready** (สัปดาห์ที่ 6–9)

**ผู้จัดทำ:** อนุพันธ์ เอกอาภรณ์ภิรมย์

เว็บขอลาออนไลน์ เขียนด้วย **HTML · CSS · JavaScript ธรรมดา** ไม่มี framework ไม่มีขั้นตอน build
ข้อมูลอยู่บน **Firebase** (Firestore + Authentication + Hosting) และมีผู้ช่วย AI ผ่าน **OpenRouter**

## ✅ ตอนนี้ระบบทำอะไรได้แล้ว

| ความสามารถ | สถานะ |
|---|---|
| สมัครสมาชิก · เข้าสู่ระบบ · ออกจากระบบ | ✅ Firebase Authentication (อีเมล + รหัสผ่าน) |
| ยื่นใบลา · ดูรายการ · ดูรายละเอียด · ลบใบของตัวเอง | ✅ บันทึกลง Firestore จริง |
| เขียนความเห็น · อนุมัติ / ไม่อนุมัติ | ✅ บันทึกลง Firestore จริง |
| คุมสิทธิ์ตามบทบาท `employee` · `manager` · `hr` | ✅ ทั้งฝั่งหน้าจอ (`js/acl.js`) และฝั่งฐาน (`firestore.rules`) |
| 🤖 **AI ระดับ 1** — ปุ่มให้ AI จัดประเภทการลาจากเหตุผลที่กรอก | ✅ ในหน้ายื่นใบลาใหม่ |
| 🤖 **AI ระดับ 2** — ปุ่มให้ AI สรุปใบลาให้หัวหน้าอ่านก่อนกดอนุมัติ | ✅ ในหน้ารายละเอียดใบลา |
| โหมดสว่าง / มืด | ✅ ปุ่มในแถบเมนูทุกหน้า จำค่าไว้ข้ามหน้า |
| ทดสอบอัตโนมัติ | ✅ Playwright + Playwright MCP |

> 🔒 **AI เสนอ ไม่ได้ตัดสิน** — ทุกอย่างที่ AI แนะนำมีป้ายกำกับและคนแก้ทับได้เสมอ
> สถานะใบลาเปลี่ยนได้ด้วยการกดปุ่มของคนที่มีสิทธิ์เท่านั้น และ `firestore.rules` บังคับข้อนี้ไว้อีกชั้น

### ⚠️ ส่วนที่ยังค้างอยู่

- **ประเภทการลายังเป็นข้อมูลที่พิมพ์ค้างไว้ใน `js/data.js`** — หน้า *ประเภทการลา* แก้ได้บนหน้าจอ แต่กด F5 แล้วกลับค่าเดิม ยังไม่ได้ต่อ Firestore
- **คีย์ AI ยังอยู่ฝั่งเบราว์เซอร์** — กด F12 บนเว็บก็เห็นคีย์ · 📝 Backlog Sprint 2 คือย้ายไปไว้ฝั่งเซิร์ฟเวอร์
- **ข้อมูลตัวอย่าง `u001`–`u003` และ `lr001`–`lr005` ไม่ผูกกับบัญชีจริงของใคร** จึงไม่ขึ้นให้ใครเห็นหลังจากกรองด้วย `uid` แล้ว

## 🚀 เอาไปรันเองยังไง

```bash
npm install
npm run dev
```

เปิด <http://localhost:3000>

### 🔑 ต้องใส่คีย์ AI ก่อน ปุ่ม AI ถึงจะทำงาน

คีย์ **ไม่ได้อยู่ใน repo** และจะไม่มีวันอยู่ — ต้องสร้างไฟล์เอง

```bash
cp js/ai-key.example.js js/ai-key.js
```

แล้วเปิด `js/ai-key.js` วางคีย์ OpenRouter ที่ผู้สอนแจกให้ลงไป

- `js/ai-key.js` ถูก `.gitignore` กันไว้ — **ห้ามเอาคีย์ไปวางในไฟล์อื่นเด็ดขาด**
- ยังไม่ใส่คีย์ก็เปิดเว็บได้ตามปกติ แค่ปุ่ม AI จะขึ้นข้อความบอกว่ายังไม่ได้ใส่คีย์
- ⚠️ ใช้ได้เฉพาะคีย์ของหลักสูตรเท่านั้น **ห้ามใช้คีย์ส่วนตัว**

### คำสั่งอื่น

```bash
npm test                            # รัน Playwright ทดสอบกับเว็บจริง
npm run rules:deploy                # ส่ง firestore.rules ขึ้น Firebase
npx firebase deploy --only hosting  # ส่งเว็บขึ้น Firebase Hosting
```

```
หน้าเว็บ
  index.html                  หน้าแรก

  leave-request-detail.html   รายละเอียดใบลา + ความเห็น + 🤖 ปุ่ม AI สรุป
  leave-types.html            ประเภทการลา (เฉพาะ hr)
  ai-test.html                หน้าทดสอบเรียก AI ครั้งเดียว
  seed.html                   เครื่องมือใส่ข้อมูลตัวอย่าง ใช้ครั้งเดียวตอนตั้งระบบ

โค้ดส่วนกลาง — แก้ที่เดียว ทุกหน้าเปลี่ยนตาม
  js/firebase-init.js         ตั้งค่าเชื่อม Firebase
  js/auth.js                  เรื่องล็อกอินทั้งหมดอยู่ที่นี่ที่เดียว
  js/acl.js                   ใครทำอะไรได้บ้าง (ดู ACL.md)
  js/ai.js                    ประตูบานเดียวที่คุยกับ AI
  js/ai-key.js                🔴 คีย์ AI · .gitignore กันไว้ · ต้องสร้างเอง
  js/theme.js                 โหมดสว่าง/มืด · โหลดใน <head> ห้ามใส่ defer
  js/nav.js · icons.js · util.js   แถบเมนู · ไอคอน · ตัวช่วยที่ใช้ร่วมกัน
  js/data.js                  ⚠️ ประเภทการลา ยังเป็นข้อมูลที่พิมพ์ค้างไว้

กฎและเอกสาร
  firestore.rules             🛡️ ยามเฝ้าข้อมูลตัวจริง — แก้แล้วต้อง deploy ด้วย
  CLAUDE.md                   กติกาที่ Claude Code ต้องอ่านก่อนแก้โค้ด
  ACL.md                      ตารางสิทธิ์รายบทบาท
  leaveeasy-spec.md           ข้อกำหนดฉบับเต็มของระบบ

ทดสอบ
  playwright.config.js        ชี้ไปที่เว็บจริงบน Firebase Hosting
  tests/smoke.spec.js         เทสต์ควันไฟ ไม่ต้องล็อกอิน
  .mcp.json                   เชื่อม Playwright MCP เข้ากับ Claude Code
```

> 💡 **`CLAUDE.md` กับ `leaveeasy-spec.md` สำคัญกว่าที่คิด** — Claude Code อ่านเองอัตโนมัติ
> แล้วใช้ชื่อโฟลเดอร์ · ชื่อช่องข้อมูล · ค่าสถานะ ได้ถูกต้องโดยที่คุณไม่ต้องพิมพ์เองทุกครั้ง
